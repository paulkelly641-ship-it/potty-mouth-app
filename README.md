# Potty Mouth Songwriter: app store kit
- `www/index.html`: the app (works offline, no dependencies)
- `BUILD_STEPS_ANDROID.md` + `store/PLAY_STORE_LISTING.md`: Google Play
- `BUILD_STEPS_IOS.md` + `store/APP_STORE_LISTING.md`: Apple App Store
- `store/`: icons, feature graphic, privacy policy
Set your own `appId` in `capacitor.config.json` before building.
